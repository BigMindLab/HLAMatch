Acerca de HistoMatch

HistoMatch es una aplicación de escritorio basada en Python diseñada para automatizar el análisis de compatibilidad HLA. Proporciona una interfaz gráfica intuitiva construida con Tkinter, permitiendo a los usuarios automatizar el análisis de histocompatibilidad y la generación de reportes.

Automatiza la evaluación de compatibilidad HLA en cinco loci clásicos, clasificando cada uno en cinco categorías y generando un puntaje global (1–10).

Estructura del Proyecto

  • main.py
  • hla_finder.py – extrae datos HLA de archivos PDF/Word y los exporta a CSV
  • histomatch_analisis.py – analiza el CSV y exporta los resultados de compatibilidad a un archivo DOCX ("Analisis_HLA")
  • histomatch_reporte.py – resume la información clave de "Analisis_HLA" en un reporte DOCX ("Reporte_HLA")

Instalación

  1. Descarga los cuatro scripts del repositorio (main_app.py, hla_finder.py, histomatch_analisis.py, histomatch_reporte.py). También se incluyen dos archivos HLA de ejemplo.
  2. Instala los paquetes requeridos:
    3. pip install pdfplumber pandas python-docx pywin32
  3. Ejecuta la aplicación desde tu terminal:
    4. python main.py

Tutorial de HistoMatch

  1. Ejecuta la aplicación en tu terminal: 
    python main_app.py
  2. Carga los resultados HLA del paciente y del donante.
  3. Haz clic en "Iniciar Procesamiento".
  4. Los resultados se generarán y descargarán automáticamente.
